# Classical Machine Learning on the Iris Dataset

A comprehensive exploration of classical machine learning techniques applied to the [Iris dataset](https://archive.ics.uci.edu/ml/datasets/iris), originally introduced by R.A. Fisher (1936). The project covers the full pipeline — from exploratory data analysis and dimensionality reduction to Gaussian classifiers, logistic regression, SVMs, and GMMs — implemented from scratch in Python using NumPy and SciPy.

## Dataset Overview

The Iris dataset contains **150 samples** (instances) of iris flowers belonging to **3 classes** (50 each):

| Class | Label |
|-------|-------|
| Iris Setosa | 0 |
| Iris Versicolor | 1 |
| Iris Virginica | 2 |

Each sample is described by **4 features**: sepal length (cm), sepal width (cm), petal length (cm), petal width (cm).

## How to Run

### Prerequisites

| Package | Purpose |
|---------|---------|
| Python ≥ 3.8 | Runtime |
| NumPy | Linear algebra, data manipulation |
| SciPy | Optimization (L-BFGS-B), special functions |
| Matplotlib | Plotting |
| scikit-learn | Dataset loading (`load_iris`) |

Install dependencies:

```bash
pip install numpy scipy matplotlib scikit-learn
```

### Running the Notebooks

1. Launch Jupyter from the project root:
   ```bash
   jupyter notebook
   ```
2. Open notebooks in order (`01_` → `07_`). Each notebook imports helpers from `scripts/` using relative imports (e.g. `from scripts.utils import *`), so **Jupyter must be started from the repository root**.
3. Run all cells top-to-bottom. Plots are rendered inline and also saved to the `images/` directories.

### 02 — PCA and LDA

Dimensionality reduction applied to the full 3-class dataset.

#### PCA (2 components)

![PCA Projection](images/pca_projection.png)

- The first principal component captures most of the total variance
- Setosa is clearly separated along PC1; versicolor and virginica overlap more than with the original petal features

#### LDA (2 components)

![LDA Projection](images/lda_projection.png)

- Being supervised, LDA achieves a much sharper class separation than PCA
- All three classes form distinct, well-separated clusters

#### LDA Binary Classifier (Versicolor vs Virginica)

The binary dataset (100 samples, 50 per class) is split 2/3 training – 1/3 validation (seed = 0).

**LDA-only results:**
- Threshold: 4.079 | Errors: 2/34 | **Error rate: 5.9%**

![LDA Binary Histograms](images/lda_binary_histograms.png)

**PCA + LDA results** (varying PCA dimensionality `m`):

| PCA dims (m) | Threshold | Errors | Error Rate |
|:---:|:---:|:---:|:---:|
| 1 | 10.885 | 4 | 11.8% |
| 2 | 5.354 | 2 | 5.9% |
| 3 | 4.535 | 2 | 5.9% |
| 4 | 4.079 | 2 | 5.9% |

Key takeaway: the first PCA component alone loses discriminative information (maximizing variance ≠ maximizing class separability). With m ≥ 2, PCA+LDA matches pure LDA performance.

### 04 — Gaussian Classifiers

Three multivariate Gaussian classifiers are compared on the 3-class problem, followed by binary (versicolor vs virginica) evaluation.

#### Model Definitions

| Model | Covariance Structure | Decision Boundary |
|-------|---------------------|-------------------|
| **MVG** (Full) | Per-class $\Sigma_c$ | Quadratic |
| **Naive Bayes** | Per-class diagonal $\text{diag}(\Sigma_c)$ | Quadratic (axis-aligned) |
| **Tied Covariance** | Shared $\Sigma$ across classes | Linear |

#### 3-Class Results

| Model | Error Rate | Accuracy |
|-------|:---:|:---:|
| MVG | 4.0% | 96.0% |
| Naive Bayes | 4.0% | 96.0% |
| **Tied Covariance** | **2.0%** | **98.0%** |

#### Binary Results (Versicolor vs Virginica)

Classification via log-likelihood ratio: $s(x)=\log f(x \mid C{=}2) - \log f(x \mid C{=}1)$, with threshold $t=0$ under equal priors.

| Model | Error Rate | Accuracy |
|-------|:---:|:---:|
| MVG | 8.82% | 91.18% |
| Naive Bayes | 11.76% | 88.24% |
| **Tied Covariance** | **5.88%** | **94.12%** |

Tied Covariance achieves the best result, matching the LDA error rate (~5.9%), consistent with the theoretical equivalence between LDA and Gaussian classification with shared covariance.

### 05 — Logistic Regression

Binary logistic regression (versicolor vs virginica) with L2 regularization, optimized via L-BFGS-B. Evaluated with error rate, min DCF, and actual DCF.

#### Standard Logistic Regression

| $\lambda$ | Error Rate | min DCF ($\pi$=0.5) | actual DCF ($\pi$=0.5) |
|:---:|:---:|:---:|:---:|
| $10^{-3}$ | 8.8% | 0.0625 | 0.1181 |
| $10^{-1}$ | 11.8% | **0.0556** | **0.1111** |
| $1$ | 14.7% | 0.1111 | 0.1667 |

Best trade-off: $\lambda=10^{-1}$ (lowest min DCF and actual DCF).

#### Prior-Weighted Logistic Regression ($\pi_T$ = 0.8)

| $\lambda$ | Error Rate | min DCF ($\pi_T$=0.8) | actual DCF ($\pi_T$=0.8) |
|:---:|:---:|:---:|:---:|
| $10^{-3}$ | 11.8% | 0.1667 | **0.2222** |
| $10^{-1}$ | 38.2% | **0.0556** | 0.7222 |
| $1$ | 52.9% | 0.1111 | 1.0000 |

The weighted variant shows a large gap between min DCF and actual DCF, indicating poorly calibrated scores. Without post-hoc calibration, the standard variant is more robust.

### 07 — GMM

Gaussian Mixture Model classifier on the full 3-class problem, using the LBG splitting algorithm with constrained EM (eigenvalue floor $\psi$).

| GMM Components | Error Rate |
|:---:|:---:|
| 1 | 4.00% |
| 2 | 4.00% |
| 4 | 4.00% |
| 8 | 4.00% |
| 16 | 4.00% |

Performance is **stable** across all component counts — Iris is simple enough to be well-modeled by single Gaussians per class. The covariance regularization ($\psi$) prevents numerical degeneracies during EM.

## Utility Functions Reference

A summary of the helper functions organized by module. All scripts are in the `scripts/` directory.

### `utils.py` — Data Loading & Statistics
| Function | Description |
|----------|-------------|
| `init_dataset()` | Loads full Iris dataset, returns features, labels, class/feature names |
| `init_dataset_for_binary_classification()` | Loads Iris filtered to classes 1 and 2 only |
| `load_iris_binary()` | Loads binary Iris with labels remapped to {0, 1} |
| `split_db_2to1(D, L, seed)` | 2:1 train/validation split |
| `getMu(D)` | Mean vector |
| `getC(D)` | Sample covariance matrix |
| `getRow(v)` / `getCol(v)` | Reshape to row/column vector |
| `compute_Sb_Sw(D, L)` | Between-class and within-class covariance matrices |
| `get_hist(...)` / `get_scatters(...)` | Histogram and scatter plot generation |

### `dimensionalityreduction.py` — PCA & LDA
| Function | Description |
|----------|-------------|
| `train_PCA(X, m)` | Computes PCA projection matrix (top `m` eigenvectors) |
| `apply_PCA(X, P, mu)` | Projects data onto PCA subspace |
| `train_LDA(X, L, m)` | Computes LDA transformation matrix |
| `apply_LDA(X, W)` | Projects data onto LDA subspace |

### `loglikelihood.py` — Gaussian Density
| Function | Description |
|----------|-------------|
| `logpdf_GAU_ND(x, mu, C)` | Multivariate Gaussian log-pdf |
| `loglikelihood(XND, m_ML, C_ML)` | Total log-likelihood of a dataset under a Gaussian model |

### `pca_lda_classifiers.py` — LDA-Based Classifiers
| Function | Description |
|----------|-------------|
| `LDA_classifier(DTR, LTR, DVAL, LVAL)` | Train & evaluate LDA binary classifier |
| `LDA_with_PCA_classifier(DTR, LTR, DVAL, LVAL, m)` | Train & evaluate PCA+LDA binary classifier |

### `gaussianclass.py` — Gaussian Classifiers
| Function | Description |
|----------|-------------|
| `get_params_MVG(DTR, LTR)` | Estimate MVG parameters (per-class mean & covariance) |
| `get_params_Naive_Bayes(DTR, LTR)` | Estimate Naive Bayes parameters (diagonal covariance) |
| `get_params_Tied_Covariance(DTR, LTR)` | Estimate Tied Covariance parameters (shared covariance) |
| `getS(...)` / `getSJoint(...)` / `getSPost(...)` | Score, joint probability, and posterior computation |

### `logisticreg.py` — Logistic Regression
| Function | Description |
|----------|-------------|
| `trainLogReg(DTR, LTR, l)` | L2-regularized binary logistic regression (L-BFGS-B) |
| `weighted_trainLogReg(DTR, LTR, l, piT)` | Prior-weighted logistic regression |

### `SVM.py` — Support Vector Machines
| Function | Description |
|----------|-------------|
| `train_SVM(K, C, DTR, LTR)` | Dual linear SVM |
| `train_kernel_poly_SVM(...)` | Dual polynomial-kernel SVM |
| `train_kernel_KRB(...)` | Dual RBF-kernel SVM |
| `polygrad_d(...)` / `KRB(...)` | Polynomial / RBF kernel matrices |
| `regular_kernel(kernel, xi)` | Add bias regularization to kernel |

### `GMM.py` — Gaussian Mixture Models
| Function | Description |
|----------|-------------|
| `logpdf_GMM(X, gmm)` | Component and marginal log-densities |
| `EM_constrained(...)` | Constrained EM algorithm (eigenvalue floor) |
| `split_gmm(gmm, alpha)` | Split GMM components (LBG step) |
| `LBG_constrained(...)` | Full LBG algorithm to grow a GMM |

### `bayes_error.py` — Evaluation Metrics
| Function | Description |
|----------|-------------|
| `get_confusion_mat(predictions, L)` | Confusion matrix |
| `DCF_u(...)` / `DCF_norm(...)` | Unnormalized / normalized Detection Cost Function |
| `get_bayes_decision(llr, pi, Cfn, Cfp)` | Bayes-optimal thresholding on log-likelihood ratios |
| `compute_min_dcf(...)` | Minimum DCF over all thresholds |
